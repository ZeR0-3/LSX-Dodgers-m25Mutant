# 漢字表示(Shift_JIS)

状態: エミュレータで、4イメージとも全角の表示・モード切替・無効な2バイト目・行末を確認(test_all 4本)。**実機未確認**。

## 使い方
- `KMODE` または `KMODE ON` で漢字モードON、`KMODE OFF`(`KMODE 0`)でOFF。実体は `ESC k 1` / `ESC k 0` をコンソールに出すだけ(プログラムからも出せる)。起動時はOFF。
- ON の間、Shift_JIS の1バイト目(81H-9FH, E0H-FCH)が来たら次のバイトと合わせて全角1文字(横2セル)で表示する。A1H-DFH(半角カナ)と他のコードは今までどおり。
- 無効な2バイト目(40H未満, 7FH, FDH以上。CR/LF含む)なら、1バイト目は捨てて2バイト目を普通の文字として処理する。行の最後の桁に来た全角は、1セル空けて次の行へ出す。
- ファイル名は今までどおり(日本語のファイル名は未確認)。`type` で Shift_JIS のテキストを見るには、先に `KMODE`。

## 仕組み
- 漢字ROMのセル指定(資料「第7-2表 テキストV-RAM1」「第7-4表 V-RAM2」)。1セル = Text1(b7-b2=A10-A5, b1=0左/1右, b0は縦12行のみ)+属性+Text2(b7=K, b6=L(0=第1水準/1=第2水準), b5-b0=A16-A11)。
- JIS区点 → グリフ番号 idx(32バイト単位): 区21H-28H: `(区-21H)*60H + 点-20H` / 区30H-74H: `400H + (区-30H)*60H + 点-20H`(区50H以降が第2水準で L=1 に当たる)。
  Text1(左)=`(idx&3FH)*4`、Text1(右)=左+2、Text2=`80H|(idx>>6)`(idx は13ビット)。区29H-2FH/75H以降は空白2セル。
- ROMのグリフ番号の対応は、エミュレータの漢字ROMを画像にして実測し、資料の変換式と一致することを確認した。
- 実装: `src/M25KJ.ASM`(375B。色の指定を含む)。ORG KJBASE(A3D0H)で別にアセンブルし、`LD2500.BIN` のシステム部の中に埋め込んで、INIT がカーネル時のバンク5の空き(行編集バッファの後ろ)へ写す。
  本体(`M25IO.ASM`)の変更は PRINT の `CALL KJLEAD / JR Z,PRINTE5`、`ESC2` の `JP NZ,KJTRAIL`、`ESC1Z` の `JP NC,KJESC` の3か所だけ(本体の空きは減っていない)。
  1バイト目は `ESCYP+1`(ESC Y の作業バイト)、状態は ESCFLG=4 で次の1文字を `ESC2` → `KJTRAIL` へ回す。モード(KJEN)はモジュール内のデータ。
- (行編集をオーバーレイに移したので、履歴を減らしたのは一時的で、今は 50 件。docs/line-edit.md)

## 同時に直したこと
- `COPY` などのバッファ(`S27BUF`)は SP から逆算するので、約40KBを超えるファイルで、カーネル時のバンク5の空き(A000H以降)を踏んでいた。`build.py` の patch で 0100H-98FFH までに止めた(これがないと漢字のコードが壊れる)。

## 制限
- カーソル移動・BS・削除は1セル単位なので、全角の途中で消すと半分の字が残る。行の途中に挿入するモード(INSERT)は未対応。
- 行編集(履歴・TAB補完)は全角を1文字として扱わない。
- UTF-8 は未対応(後で外部コマンドで、の方針)。Shift_JIS ↔ JIS の変換だけで、JIS X 0208 の範囲(区21H-28H, 30H-74H)。
- 実機の漢字ROMのアドレス指定は、資料とエミュレータの一致までしか確認していない。

## 色(同じモジュールに入っている)
- `ESC b n` : 文字色。n は ANSI 順(0黒 1赤 2緑 3黄 4青 5紫 6水色 7白)。MZ-2500 の属性(b0=青 b1=赤 b2=緑)へは `KJCOL` で変換する。
- `ESC p` / `ESC q` : 反転 ON / OFF(Atari の ESC p/q に合わせた)。属性の b6。
- **背景色は独立に指定できない**: テキスト属性は 1 セルに色が 1 つだけで(第7-3表)、反転にすると「文字が透明、背景が b2〜b0 の色」になる。ESC c(背景色)は作らず、「`ESC b n` + `ESC p`」で色付き背景(文字は黒)にする。
- `ESC [ n;n;... m` : VT-100 の SGR の一部。`0`(または引数なし)=白・反転解除、`7`=反転、`27`=反転解除、`30-37` / `90-97`=文字色(ANSI順。明るい色は通常色と同じ扱い)、`39`=白。`1`(太字)・`4`・`40-47`(背景色。独立指定不可)などは**無視**する。`m` 以外の終端(`ESC [ ? 25 h` など)は何もせず読み飛ばす。引数は 0-255 を想定(10進を1バイトで累積)。実装は M25IO.ASM の `CSI`/`SGR`(本体)と M25KJ.ASM の `KJTRL`(KJST=6)。漢字モジュールは 399 バイトで、LDVARS(A560H) まで残り 1 バイト。
- `COLOR.COM [0-7] [R] [N]` : 数字=ESC b、R=ESC p、N=ESC q。引数なしは白・反転OFFに戻す。属性の b7(ブリンク)は未対応。
- プロンプトに戻っても色は自動では戻らない(`color` で戻す)。
- テスト: `tests/col_text.asm` が出す RGBXWCY のアトリビュートが `02 04 01 41 07 05 06` になること(phys 70800H)。**実機未確認**。

## UTF-8 の変換(2026-11-12): utf8.COM
- `utf8 [-c] [file ...]` / 標準入力 → 標準出力。UTF-8 を Shift_JIS(JIS X 0208 + 半角カナ)へ。`-c` は LF だけの改行を CR LF に。`utf8 -c note.txt > note.sjs`、`cat note.txt | utf8`、`utf8 < note.txt` が動く(エミュレータでテスト済み)。
- 変換表 `coms/utf8tab.inc`(約6900文字、Unicode昇順、2分探索)は `tools/gen_utf8tab.py` が Python の shift_jis/cp932 から作る(NEC/IBM拡張=87区・ED/EE・FA-FC は含めない)。COM は約28KB。
- 表に無い文字・4バイトの UTF-8(絵文字)は `?`。¥(U+00A5)は 5Ch、全角チルダ(U+FF5E / U+301C)は 8160h。
- 逆(Shift_JIS → UTF-8)と、日本語ファイル名はまだ無い。表示は `kmode on` が必要(漢字ROMの実機は未確認)。
- **sjis.COM(逆変換、2026-11-12)**: `sjis [-l] [file ...]` / 標準入力 → Shift_JIS を UTF-8 へ。`-l` は CR を取って LF だけにする。表 `coms/sjistab.inc`(Shift_JIS昇順、約6900文字、cp932の対応で全角チルダ=U+FF5E)は同じ `tools/gen_utf8tab.py <utf8tab.inc> <sjistab.inc>` が作る。5Ch は `\` のまま。表に無い文字は `?`。エミュレータでテスト済み(ファイル/パイプ、全角・半角カナ・2バイトのUTF-8)。

## 日本語ファイル名(2026-11-13 確認)
元の LSX-Dodgers が Shift_JIS のファイル名を扱える(LDFILE.ASM の FKAN/FKANC が1バイト目を覚えて、2バイト目を大文字化・比較の対象から外す。先頭の E5h は 05h に置き換える)。MZ-2500 版では**コードを足さずに**そのまま動くことを確認した(エミュレータのみ)。
- 動作確認: リダイレクトでの作成(`echo abc> あい.txt`)、`cp` `mv` `touch` `cat` `wc` `hd` `grep` `egrep`、`ren` `del`(ワイルドカード `あ*.txt` を含む)、`find -name`、`ls`/`dir` の表示(`KMODE 1` で全角、半角カナも可)、`ls` のソート。試験は tests/jname.bat(4イメージ)。
- 注意: 名前は 8+3 バイト。全角は 1 文字 2 バイトなので本名は4文字まで、拡張子は1文字+1バイト。
- できないこと(実装していない): LSX の行編集には**かな漢字変換を組み込んでいない**ので、全角の名前はバッチ・リダイレクト・パイプ経由でしか入れられない(半角カナはカナキーで直接入る)。MZ-2500 本体には辞書ROM(物理ページ 3A)があり、実機ではかな漢字変換ができるはずだが、LSX からそれを呼ぶ方法は**未調査**(以前「キーボードに日本語入力は無い」と書いたのは確認不足の誤り)。行編集での全角文字のカーソル移動・BS の扱いも、入力手段が無く未検証。
- `find .` で起点に `.` を指定すると BIN\\BIN\\… と無限に降りる(日本語名とは無関係の既存の癖。起点を省略するか別のディレクトリ名を指定する)。
