# SASI ハードディスク (H:) — ドライバ・ブート・イメージ

状態: エミュレータ(MZ-1E30モデル, `--hdf`)で、(1) FD起動のLSXから H: の読み書き、(2) FD無し・ROM無し(簡易IPL)でHDDから起動、まで動作確認。**実機(MZ-1E30 + HDD/HDDエミュレータ)では未確認**。実IPLでのHDD起動はMZ-1E30のオプションROM(手元に無い)が必要で未試験。

## 構成
- `src/M25SASI.ASM` (共通バンク7、約310B): `SASRD`/`SASWT` = DPB ドライバ(IX=DPB, B=セクタ数, CDE=論理セクタ512B単位, HL=アドレス。CF=1でエラー、A=SASIステータス/80h=タイムアウト)。論理セクタ n → ブロック `SASBASE + 2n` から2ブロックを READ(6)/WRITE(6) で転送。バスはID0固定、A4h=データ A5h=選択/ステータス(bit7 REQ, bit5 BSY, bit3 C/D, bit2 I/O)。本体側(B006H-DFFFH)が満杯のため、ゲートの後(EDTの後ろ)に置いている。
- `src/M25SASIP.ASM` (INITとHDDブートローダで共用): `SASPROBE` = バスリセット→空きを確認→LAD3の"EHSASI "パーティション表を読み、**優先起動(ctrl bit7)**のLUN0エントリの先頭ブロックを `SASBASE` に設定。
- `src/M25DPB.ASM` H: = `SASI`。`DPB_DEVICE=29h`(BPBからDPBを作る/ハードディスク)。FAT12/16は LSX が総クラスタ数で判定。INITの `SASINI` が見つかったときだけ `FATLN=1` にする(無ければ H: は未使用)。
- `src/M25BOOT.ASM` に `HDDBOOT` 版(build.py が `boot_payload_hdd.bin` として別にビルド): SASPROBE で優先起動パーティションを探し、`LD2500.BIN`(+オーバーレイ)をHDDから読んで START へ。`BOOTDEV`(FF20H)=1 を立て、INITがカレントドライブを H: にする。
- `tools/make_hdd.py`: HDDイメージ作成。256B/ブロック、正規サイズ 87648 ブロック(22437888B。エミュレータは EH-SASI 署名で256B/ブロックと判定)。build.py が `LSX2500.hdf`(build_all では `LSX2500_<種類>.hdf`)を出力。

## ディスク配置
```
ブロック3          パーティション表  "EHSASI 20220510\0" + エントリ16B x 15
                   エントリ: +0 ctrl(0x81=優先起動+ドライブ1) +1,2 容量 +3 SASI-IDのビットマスク(0x01) +4 LUN +5..7 先頭ブロック(上位,中,下位)
ブロック 21h〜      パーティション(FAT16, 20000論理セクタ=約10MB, 1クラスタ2セクタ)
  論理セクタ0       IPLPROヘッダ(256B)とBPBを同居: 先頭 01 'IPLPRO'、[18h]=入口8000h、[1Eh]=ローダ開始レコード(=2)、[20h]=転送先ページ列、[30h..]=起動時バンク割当。
                    BPB(11〜23, 36, 38)はヘッダの使っていない/読み飛ばしてよい領域に重ねてある(BPBの 24〜35(セクタ/トラック・ヘッド・隠しセクタ)はヘッダの値が入る。HDDでは未使用)
  論理セクタ1〜16   ブートローダ 8KB (ブロック2〜33)
  予約=20, FAT x2 (39セクタ), ルート512エントリ(32セクタ), データ(クラスタ2 = 論理セクタ130 から LD2500.BIN を連続配置)
```
簡易IPL(エミュレータ)のHDD起動の契約: パーティション表(LAD3) → 優先起動エントリ → 先頭ブロックのIPLPROヘッダ → `[1Eh]` 起点に `バンク数×32` ブロック連続。

## 未確認・注意
- 実機のMZ-1E30が見るパーティション表/IPLレコードの形式は、公開されているEnhanced SASI driverの仕様書(参照のみ、コードは取り込んでいない)とエミュレータの契約に合わせたもの。容量フィールドの単位、SASI-IDの扱い(ここではビットマスク0x01)は未確認。
- 受信/送信ループはデータ転送中のタイムアウトを持たない(コマンド送出・ステータス受信・選択にはある)。
- 1ドライブの論理セクタ番号は CDE の24ビット(DPB規約)だが、本ドライバは `SASBASE`(5ビット上位)を足して21ビットLBAまで。
- 複数パーティション(HD1〜HD4相当)、LUN1、フォーマット/パーティション作成ツールは未実装。イメージはPCで作る。

## retropc.net MZ-1E30 ページ(コピペ)で確認できたこと・反映内容
- A5h 読み: bit7 REQ / bit6 ACK / bit5 BSY / bit4 MSG / bit3 C/D / bit2 I/O / bit0 割込み。書き: bit5 SEL / bit3 RST。bit1(DMA許可)・bit0(割込み許可)は MZ-2500 では 0 にする。ACK は A4h アクセスで自動。
- 選択手順(A5 bit5=0確認 → A4←01h → A5←20h → BSY待ち → A5←0)は実装と一致。
- 反映: データ転送/コマンド送出の REQ 待ちを「REQ=1 かつ ACK=0」に変更。SASPROBE は A5h=FFh を基板なしと判定し、BSY=1 の間だけバスリセットから最大3回(約0.4秒間隔)再試行。選択に応答しない(HDD無し)場合は待たず終了(待つとFD起動が遅れ、テストが落ちたため)。スピンアップ待ちとしては限定的。
- 注意: 実機 MZ-1E30 の ROM は独自の HDD フォーマット/ブート(レコード0=boot, 1-3=ブート処理, 4=常駐, 5-8=read/write/pre/init)で、IOCS の HDD 拡張は BASIC 向け。本実装のパーティション表+IPLPRO ヘッダ方式は Enhanced SASI ROM/エミュレータ向けで、純正ROMでの起動は未確認。
- MZ-2500 は 20MB(22437888B)固定、BASIC からは10MB区画。末尾 1655808B は出荷ゾーン。
- いずれも実機未検証。エミュレータ上のテスト(SASI H: 読み書き4種, HDDブート4種)は PASS。

## ドライブ文字・ファイル配置(2026-11-09)
- HDD は **H:**(G: は将来用に空けてある。X1 では GVRAM をドライブにする実装があり、HDD は H: のため合わせた)。HDDから起動するとプロンプトは `H>`。
- 付属コマンドは `\BIN` に入れた(FD は `A:\BIN`、HDD は `H:\BIN`)。ルートには `LD2500.BIN` と `AUTOEXEC.BAT`(FD は `path a:\bin`、HDD は `path h:\bin` と `hist h:\history.txt`)だけ。履歴ファイルは `H:\HISTORY.TXT`(docs/line-edit.md)。
- `tools/d88_put.py`(`BIN/NAME.COM` の形でサブディレクトリを作って書く。ディレクトリは足りなければ延ばす)と `tools/make_hdd.py`(`path:BIN/NAME.COM`)が対応。
- TAB補完はPATHの中までは探さない(カレントとコマンド名だけ)。
