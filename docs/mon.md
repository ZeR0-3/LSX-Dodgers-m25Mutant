# MON.COM(IOCS非依存の外部モニタ) — 2026-11-08

BDOS 2/9/0Ah だけで動く通常のCOM(coms/mon.asm、ビルド時に自動で起動ディスクへ入る)。
内蔵の旧モニタ(IOCS機能00h)は `IMON` に改名して残してある。

| コマンド | 内容 |
|---|---|
| D [始 [終]] | ダンプ(省略時は続き) |
| M 番地 [バイト..] | 書換。バイトなしは対話(空行=次へ、`.`=終了) |
| F 始 終 値 | 埋める |
| G 番地 | CALL(RETで戻る) |
| L [番地 [行数]] | 逆アセンブル(既定16行、続き) |
| A 番地 | 簡易アセンブラ(`.`か空行で終了、組んだバイトを表示) |
| I ポート / O ポート 値 | I/O 読み書き |
| P | MZ-2500 I/Oポート一覧 |
| H, ? / Q | ヘルプ / 終了 |

数値は16進。アセンブラ内の数値は 0〜9 で始める(`0FFH`、`10`)。`DB`/`DW` 対応。
アセンブラは逆アセンブラのテキスト(数値の場所だけ n/w/d/e)をテンプレートにして全オペコードを総当たりで照合する方式
(CB/ED/DD/FD/DDCB 対応。未公開命令は非対応)。
テスト: tools/test_all.sh の「MON.COM(A/L/F/D)」(全4種で PASS)。全体 177/177。
