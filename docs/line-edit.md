# 行編集(TAB補完・履歴・^F)— オーバーレイ版

状態: エミュレータで、TAB補完(ファイル名/コマンド名/一覧)、履歴(↑↓ ^P ^N)、^F(部分一致)、履歴の深さ(12件さかのぼる)を4イメージで確認。**実機未確認**。

## 構成(2026-11-09)
- 常駐 `src/M25EDT.ASM`(小さい): `ED_BEGIN`(開始位置・履歴位置の初期化)、`HND_CCPIN`(プロンプト入力。入力後に履歴へ追加)、`ED_KEY`(キー入力のフック。Ctrl-Z のEOF処理、TAB/^P/^N/^F/↑/↓ のときだけオーバーレイを呼ぶ)、変数(`EDT_OK` `EDT_START` `EDT_POS` `EDT_EOFM/K`)。`M25GATE.ASM` と `M25SASI.ASM` もここから取り込む(共通バンク7)。
- オーバーレイ `src/M25EDTO.ASM`(約1.4KB+バッファ): 補完・履歴・検索の本体。入口は 7=`EDO_KEY`(C=キー。処理したら CF=1、BC保存)、8=`EDT_ADD`(履歴追加)。
- 履歴 `EDT_N`=50 件(1件80B=4000B)と作業バッファ(約500B)はオーバーレイのページ(0Eh)の中。ページは起動時に読み込まれたまま残るので、履歴も残る(リセット/電源断で消える)。
- 呼ぶのは `EDT_OK`=1(CCPのプロンプト入力)の間だけ。プログラムの BDOS 0Ah(行バッファが 8000H-9FFFH にありうる)では、窓(バンク4)を使うオーバーレイは呼ばず、元の動作のまま。

## 効果
- 常駐側の空き: 共通領域の `free` が 47B → 約1082B(本体 B006-DFFF 側も約1.4KB空いた)。
- バンク5の A000H-A3CFH 付近が空いた(以前の履歴バッファ)。
- 履歴 7件 → 50件。

## 制限
- オーバーレイの呼び出し分(DI→窓の切替→EI)だけ、対象のキーでは少し遅い。

## 履歴ファイルと HIST コマンド(2026-11-09)
- 内部コマンド `HIST`(4文字。オーバーレイの入口9、`M25EDTO.ASM`):
  - `hist` : 履歴(RAM)を古い順に表示。
  - `hist パス` : 履歴ファイルを設定。ファイルがあれば末尾約4KBを行に分けて履歴へ読み込み、以後、プロンプトで Enter した行を1行ずつ `CR LF` 付きで追記する(空行と直前と同じ行は入れない)。ファイルが無ければ最初の追記で作る。
  - `hist off` : 追記をやめる(RAM の履歴はそのまま)。
- HDD の `AUTOEXEC.BAT` に `hist h:\history.txt` を入れてある(`path h:\bin` の次の行)。FD の AUTOEXEC.BAT には入れていない(Enter のたびに FD へ書くのは遅く、書込禁止にも弱いので、使いたい人が自分で `hist b:\history.txt` などを実行する)。
- 追記は M25HND と同じ 26h/27h(レコードサイズ1=バイト位置)で、FCB とバッファはバンク5の空き(A000H-、`HFCB` `HIOB` `HLBUF`)。ファイルの大きさは FCB の +16。LSXの規則で FCB+28 が FFH のとき成功。
- 履歴の件数(`EDT_N`)は 50。ファイルは増え続ける(古い分は `cat` `more` `grep` で見る)。起動時の読み込みは末尾約3968バイトだけ。
- AUTOEXEC.BAT の行や、プログラムの BDOS 0Ah(行入力)は履歴に入らない(CCPのプロンプト入力だけ)。
- テスト: HDD 起動で入力 → `cat h:\history.txt` の内容 → 保存した HDD で再起動して `hist` に読み込まれていること、`hist off` で追記が止まること(4イメージ)。**実機未確認**。
