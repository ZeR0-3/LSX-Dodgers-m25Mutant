EGREP  行の検索(正規表現つき)

  egrep [-ivnclwoh] [-A n] [-B n] [-C n] パターン [file ...]
  パターン: 文字  .(任意)  [abc] [a-z] [^x]  ^ $  * + ?  a|b  ( )  \x(x そのものの文字)
            \<(単語の始め)  \>(単語の終わり)     全角(Shift_JIS)は2バイトで1文字
  空白を含むときは "..." で囲む。{n,m} と後方参照は無い。 *? のような最短一致も無い。
  -i 大小無視  -v 一致しない行  -n 行番号  -c 行数だけ  -l ファイル名だけ
  -w 単語として一致  -o 一致した部分だけ  -h ファイル名をつけない
  -A n 後ろ n 行  -B n 前 n 行  -C n 前後 n 行  (n は 0-9。グループの間は -- )
  file は複数・ワイルドカード可(同じディレクトリ)。省略=標準入力。複数のときは  ファイル名:行
  終了コード: 一致あり 0 / なし 1 / 開けないファイルあり 2
  例) egrep -n "^(cd|dir)" *.bat    ls -l | egrep "\.COM$"    egrep -o "[0-9]+" a.txt
