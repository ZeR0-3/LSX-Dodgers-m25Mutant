SED  ストリームエディタ(行ごとの編集)

  sed [-nE] [-e スクリプト] [-f スクリプトfile] [スクリプト] [file ...]
  file 省略=標準入力。 複数・ワイルドカード可。 結果は標準出力(> でファイルへ)。 -n = 自動表示しない
  -E (または -r) = 拡張正規表現 ( ) | + ?   既定は BRE = \( \) \| \+ \?  (どちらも後方参照 \1-\9 が使える)
  コマンド行は127文字まで。長いときは -f file。 空白や ; > を含むスクリプトは "..." で囲む。 $ は $$ と書く。

[アドレス] 行番号   $(最後の行)   /正規表現/ (後ろに I で大小無視)   \c正規表現c (区切りが c)
           先頭,末尾  (行/正規表現/$)   先頭,+N   0,/正規表現/   アドレス!コマンド (逆)
[コマンド] s/正規表現/置換/[フラグ]   y/元の文字/先の文字/
           p 表示  P 最初の改行まで表示  d 削除  D 最初の改行までを削除して読まずにやり直し
           n 次の行へ(表示してから)  N 次の行を足す  g G h H x ホールドスペース  z 空にする
           = 行番号を表示  q[n] 終了(終了コード n)  Q[n] 表示せず終了
           a テキスト  i テキスト  c テキスト   (a\ 改行 テキスト も可。複数行は行末に \ )
           b [ラベル]  t [ラベル]  T [ラベル]  :ラベル     { コマンド ; ... }     # コメント
[s の置換] & = 一致全体   \1-\9 = ( ) の中   \n 改行   \t タブ   \& \\ そのままの文字
           フラグ  g 全部  p 表示  I 大小無視  数字 = N番目から(g と併用でN番目以降)
           区切りは / 以外も可 (s|a|b|)。 空の正規表現 // は直前に使ったもの
[正規表現] 文字 . [abc] [^a-z] ^ $ * \<(語頭) \>(語末) \n \t   全角(Shift_JIS)は2バイトで1文字
           {n,m} と最短一致、[[:alpha:]] は無い

無いもの: w r e l F -i -s、\U \L \u \l \E、first~step。 行は1000バイトまで。 コマンドは100個、正規表現は32個まで。
終了コード: 0 / q の n / 1 スクリプトのエラー / 2 開けないファイルあり
例) sed s/apple/APPLE/ a.txt          sed -n 2,3p a.txt          sed "/^#/d;s/ *$$//" a.txt
    sed "s/\(.*\) \(.*\)/\2 \1/" a.txt     sed "1!G;h;$$!d" a.txt  (逆順)     sed -E "s/(a|b)+/<&>/g" a.txt
